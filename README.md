# Maison Noah - Luxury Gift Experiences

A modern, elegant website for Maison Noah, a luxury gift brand specializing in curated premium gift boxes for personal milestones and corporate moments.

## Features

- **Responsive Design** - Beautiful on all devices (mobile, tablet, desktop)
- **Modern UI** - Elegant typography and smooth animations
- **Corporate Gifting** - Dedicated section for business gifting solutions
- **WhatsApp Integration** - Direct messaging for orders and inquiries
- **Optimized Performance** - Fast loading with optimized assets

## Project Structure

```
├── index.html       # Main landing page with all sections
├── corporate.html   # Corporate gifting guide page
├── styles.css       # Main stylesheet
├── LICENSE          # MIT License
└── README.md        # This file
```

## Sections

- **Hero** - Striking introduction to Maison Noah
- **About** - Brand philosophy and values
- **Team** - Meet the makers
- **Story** - Our journey and inspiration
- **Hamper Tales** - Curated gift collections
- **Corporate** - B2B gifting solutions
- **Products** - Available gift options
- **How To Order** - Ordering process
- **FAQ** - Common questions

## Technology Stack

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with gradients, animations, and responsive grid
- **JavaScript** - Interactive features and smooth scrolling
- **Google Fonts** - Cormorant Garamond & Manrope typefaces
